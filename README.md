# Astroid

I decided to be nice and make the DLL public.

Astroid is a **very unfinished client** for Minecraft Bedrock **1.21.2**. There's still a lot of work to be done, but I figured I'd make some of it public anyway.

The client includes the **"clip bypass"** that a lot of people seem to hate. It's specifically made for the end.

No, the **source code will not be public**. This repository is only for public DLLs that I feel don't have anything particularly special or worth keeping private.

As for the usual "is this a rat?" question: **no, it isn't.** I know some people will still be skeptical, and that's fine. If you don't trust it, don't use it. I'm not going to try to convince you otherwise.

This repository will only contain DLLs that I personally decide are fine to release publicly. Don't expect every build, feature, or version of Astroid to end up here.
